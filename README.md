# Shion Park

데이터에서 출발해 사용자 여정 전체를 설계·구현하는 프론트엔드 개발자입니다.

현재 4인 스타트업에서 React·Next.js 기반 프론트엔드를 단독 운영하고 있으며,
백엔드(NestJS) API 설계부터 퍼널 분석, AI 자동화까지 서비스에 필요한 영역을 직접 만들어 운영하고 있습니다.
